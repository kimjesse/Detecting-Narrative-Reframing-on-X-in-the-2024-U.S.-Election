# Team 10 - Detecting Narrative Reframing on X in the 2024 U.S. Election 
This project contains the code files and intermediary data files for our project on identifying topics and detecting narrative reframing events during the 2024 US election. With the addition of the original data files from https://github.com/sinking8/x-24-us-election, users will be able to reproduce our methods and results contained in our report.

## Installation

```bash
# Clone the repository
git clone https://github.com/kimjesse/Detecting-Narrative-Reframing-on-X-in-the-2024-U.S.-Election.git

# Navigate to the project directory
cd Detecting-Narrative-Reframing-on-X-in-the-2024-U.S.-Election

# Install dependencies
pip install -r requirements.txt
```
